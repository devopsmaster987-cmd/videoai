# 12. AUTOMATIC YOUTUBE THUMBNAIL GENERATION

**This is a required part of the normal video-generation workflow.**

Whenever a video finishes successfully, FreeAnimate AI must automatically generate exactly three distinct YouTube thumbnail options related to that video's actual content.

The user should not need a separate application to create the thumbnails.

## 12.1 Analyze the video

Before creating thumbnails, use available project information to understand:

- Video title.
- Topic.
- Script.
- Main concepts.
- Important scenes.
- Intended audience, if specified.
- Visual style.
- Mood.
- Project language.
- Thumbnail text language.

Reuse the existing scene manifest, generated images, and other appropriate assets whenever possible.

Do not invent people, events, statistics, or other details that misrepresent the video.

## 12.2 Create three distinct thumbnail concepts

### Thumbnail 1: Recommended, high click appeal

Create a strong focal subject with:

- Clear visual hierarchy.
- Strong contrast.
- Good composition.
- Readable text when appropriate.
- Accurate representation of the video.
- A visually compelling presentation.

### Thumbnail 2: Cinematic and professional

Use:

- Cinematic composition.
- Suitable lighting.
- Professional visual balance.
- A style appropriate to the video's topic.

### Thumbnail 3: Creative alternative

Create a noticeably different composition, concept, or visual style.

It must remain relevant to the same video.

Do not create three nearly identical images with only minor color changes.

## 12.3 Use free thumbnail-generation methods

Use the following preference order:

1. Reuse appropriate generated scene images.
2. Use a compatible installed local AI image-generation model.
3. Compose original thumbnails from available images and assets using Pillow, SVG, or other suitable local tools.
4. Use procedural graphics and typography when appropriate.

Do not require paid image-generation APIs.

Do not automatically download large models.

Do not describe a procedural composition as AI-generated artwork.

If no suitable imagery is available, create the best valid composition possible using supported assets and report its limitations.

## 12.4 YouTube thumbnail specifications

Generate each thumbnail at:

- Width: 1280 pixels.
- Height: 720 pixels.
- Aspect ratio: 16:9.
- Format: JPEG.
- Color mode: RGB-compatible.
- Appropriate image quality and file size.

Validate the resulting files.

Prevent:

- Black bars.
- Unwanted borders.
- Blank images.
- Incorrect dimensions.
- Clipped subjects.
- Unreadable text.
- Broken fonts.
- Accidental transparency.
- Unrelated imagery.

Use appropriate font sizes and contrast so thumbnails remain readable at small preview sizes.

## 12.5 Multilingual thumbnail text

Generate concise thumbnail text when it improves the design.

Text should match the configured thumbnail language.

Use the full video title only when it fits naturally.

For Urdu and Arabic, ensure correct RTL direction, shaping, joining, and punctuation.

For other languages, ensure correct Unicode rendering.

If correct text rendering cannot be verified, prefer a text-free thumbnail over broken or misleading text.

Do not add unsupported claims, fake statistics, or exaggerated promises.

## 12.6 Compare and score the three thumbnails

After generating the thumbnails, evaluate them using this scoring system:

| Criterion | Maximum score |
|---|---:|
| Topic relevance | 25 |
| Visual clarity | 20 |
| Text readability | 15 |
| Contrast | 10 |
| Composition | 10 |
| Audience relevance | 10 |
| Distinctiveness | 5 |
| Honesty and accuracy | 5 |
| Total | 100 |

Implement a consistent, documented scoring method.

Scores should reflect actual evaluated characteristics, not arbitrary random values.

Use available image-processing measurements and documented heuristic rules where possible.

Explain the main strengths and weaknesses of each thumbnail.

Recommend the highest-scoring thumbnail that passes the quality checks.

Reject a thumbnail if it contains critical defects, even when its numerical score is high.

**Important:** The score is a heuristic design assessment. It is not a prediction of actual YouTube click-through rate, views, or subscriber growth.

Never claim that the recommended thumbnail is guaranteed to perform better.

   Score: 86/100

   Weaknesses: Less visually dramatic.

3. Creative — Alternative Concept
   Score: 83/100
   Strengths: Distinctive visual style.
   Weaknesses: Less immediately clear at small sizes.

RECOMMENDATION

Choose Thumbnail 1 because it provides the clearest and most relevant presentation of the video's subject.

The scores above are illustrative examples. The application must calculate the actual scores for the generated thumbnails.
