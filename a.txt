# MASTER PROMPT: FREEANIMATE AI
## A Free, Multilingual, Terminal-Based AI Animation and YouTube Video Creator

**Role:** Act as a senior Python engineer, AI video-generation engineer, multimedia developer, software architect, testing engineer, and Windows compatibility specialist.

**Mission:** Build FreeAnimate AI, a genuinely working application that converts a user's text prompt into a complete animated video using available free resources.

The application must prioritize practical functionality, zero mandatory cost, low hardware requirements, multilingual support, reliable video production, and honest reporting.

**Do not build a mockup. Do not stop after creating a plan. Inspect the existing repository, implement the software, run its tests, fix errors, and demonstrate a real end-to-end video-generation workflow.**

---

# 1. PROJECT OVERVIEW

Build an application named **FreeAnimate AI**.

It should allow a user to enter a prompt such as:

"Create a cinematic documentary explaining the history of the universe, from the Big Bang to the formation of galaxies. Use engaging narration, consistent visuals, animated scenes, subtitles, and suitable background music."

The application should automatically:

1. Understand the user's prompt.
2. Generate or prepare a script.
3. Support the selected language.
4. Organize the script into scenes.
5. Estimate the duration of each scene.
6. Create visual descriptions.
7. Generate images or video clips when compatible free tools are available.
8. Animate still illustrations when AI video generation is unavailable.
9. Generate narration through an available free text-to-speech engine.
10. Generate subtitles synchronized to narration.
11. Add appropriately licensed music and sound effects when available.
12. Assemble the scenes into a complete video.
13. Export in the selected resolution.
14. Validate the resulting video.
15. Save project information so interrupted work can resume.

The application must work through a terminal and be designed for a Windows laptop with limited CPU, RAM, storage, and potentially no dedicated GPU.

## Most important architectural requirement

**FreeAnimate AI must remain functional without a paid API, a powerful GPU, a large local AI model, or an available cloud GPU.**

Its core fallback must create real videos using meaningful visuals, animated illustrations, camera movements, transitions, narration, subtitles, and FFmpeg.

AI-generated video footage is an optional capability, not a requirement for the basic application to work.
